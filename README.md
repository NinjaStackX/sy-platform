# 🎓Sy platform | Next.js Multi-Step Course Builder Wizard

A modular, highly scalable, and RTL-native **Multi-Step Course Creation Wizard** built with **Next.js 15 (App Router)**, **TypeScript**, **Tailwind CSS v4**, and **Zustand**. Designed specifically for modern EdTech and LMS platforms requiring robust state persistence, dynamic step control, and internationalization.

## ✨ Features

- **🚀 Next.js 16 App Router & Server Actions**: Full utilization of React 19 Server Components and Type-safe Server Actions for course drafting and publishing.
- **⚡ Reactive Global State (Zustand)**: Persistent, atomic, and slice-based multi-step state management with local storage auto-save to prevent data loss on page refresh.
- **🌐 Native i18n & Full RTL Support**: Built-in seamless language switching (Arabic/English) with automatic layout direction (`dir="rtl"`) adjustment via `i18next`.
- **🛡️ Type-Safe Form Validation**: Schema-driven step validation using **Zod** and **React Hook Form** ensuring strict type safety before advancing steps.
- **📚 Dynamic Curriculum Builder**: Drag-and-drop hierarchy for modules, lessons, quizzes, and multimedia attachments.
- **🎨 Tailwind CSS v4 & Modern UI**: High-performance layout with custom animations, glassmorphism UI elements, and responsive step progress indicators.
- **💾 Auto-Draft & Cloud Sync**: Background synchronization via **TanStack Query (React Query v5)** for optimistic UI updates.
